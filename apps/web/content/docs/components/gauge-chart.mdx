## Usage

`Gauge` draws **notches** around an arc (default) or along a horizontal track (`orientation="linear"`). The center label is **optional** — omit `centerValue` for a track-only gauge.

- **Fill vs center:** `value` is the fill level **0–100**. `centerValue` is the statistic shown in the label (often the same story or a related KPI).
- **Arc center:** arc gauges overlay the label in the middle of the sweep (PieCenter-style NumberFlow + caption).
- **Linear label placement:** with `orientation="linear"`, place the label above or below the track using `labelPlacement` (`top` | `bottom`) and `labelAlign` (`start` | `center` | `end`) — the same six-position model as chart legend (top/bottom × left/center/right).
- **Responsive:** omit `width` and `height` to fill the parent. Arc gauges use **`minWidth`** (default **300**) and an aspect ratio. Linear gauges fill the parent width and use **`linearHeight`** (default **24**).
- **Linear notches:** linear gauges default to **`uniformWidth`** (rectangular notches). Pass `uniformWidth={false}` for tapered ticks.
- **Patterns / gradients in `<defs>`:** pass **[`PatternPreset`](/docs/utility/patterns)**, **`LinearGradient`**, etc. as **`children`**, then set **`activeFill`** / **`inactiveFill`** to `url(#id)`.
- **Arc gradients:** set **`useGradient`**. Optional **`activeGradient`** and **`inactiveGradient`** are **`[hexFrom, hexTo]`** tuples (interpolated along the notch index).
- **Fill opacity:** `activeFillOpacity` and `inactiveFillOpacity` map to SVG `fill-opacity` (0–1). Defaults are **1** for active notches and **0.8** for the track; docs and gallery examples use **`inactiveFillOpacity={0.4}`** for a lighter track.
- **Corner radius:** `notchCornerRadius` is the fillet in **pixels** at each notch corner (**0** = sharp). Large values are clamped by edge length and radial depth so shapes can approach a **capsule** / near-circular look.
- **Dials (arc only):** swap the notch track for a `solid` stroke or none (`arcStyle`), then layer a `ruler`, `needle`, `zones`, `sector`, `progressRing`, `dots`, `glow` and `centerDisc` — see [Dial features](#dial-features).
- **Animation:** the fill sweeps from zero on a zero-bounce spring and follows later `value` changes from where it is; reduced motion renders instantly — see [Animation](#animation).

```tsx
import { Gauge } from "@bklitui/ui/charts";

export default function RevenueGauge() {
  return (
    <Gauge
      value={66}
      centerValue={428_000}
      spacing={25}
      inactiveFillOpacity={0.4}
      defaultLabel="ARR run rate"
      formatOptions={{
        style: "currency",
        currency: "USD",
        maximumFractionDigits: 0,
      }}
    />
  );
}
```

### Linear gauge

Track-only (no label):


## Dial features

Everything below is **arc only** — `orientation="linear"` ignores these props. Layers compose freely: rings, zone bands and an outside ruler claim space from the outside in and the track shrinks to make room, so you can stack them without tuning radii by hand.

### Animation

On mount the track (and ruler) fades in, then the fill sweeps from **0** to `value` on a zero-bounce spring — notches light up in order as the sweep passes them, ruler ticks brighten, and the needle, sector, ring and dots all ride the same motion value. When `value` changes the sweep continues from wherever it is (keeping its velocity), rather than restarting from zero. With `prefers-reduced-motion` the gauge renders at its value instantly.

- **`enterTransition`** — any motion `Transition` for the sweep. Default `{ type: "spring", visualDuration: 0.9, bounce: 0 }`.
- **`enterStaggerScale`** — scales the short delay before the sweep starts (clamped **0.25–2.5**).
- **Replay** — change the gauge's `key` to remount it and play the enter again.

### Arc styles

`arcStyle` picks how the track is drawn: discrete **`notches`** (default), one rounded **`solid`** stroke (thickness via `arcThickness`, a fraction of the gauge size — default `0.035`), or **`none`** to drop the track entirely and let a sector, progress ring or dots carry the value.

With `arcStyle="solid"`, `activeFill` / `inactiveFill` colour the fill and track, and `useGradient` paints a left → right ramp (`activeGradient` or `--chart-1` → `--chart-5`).

### Ruler

`ruler` adds a scale. `true` draws 50 intervals with a major tick every 5 **inside** the track; ticks brighten as the fill passes them (`highlightActive`). Pass an object to move it **outside**, change tick counts, lengths, gap and colour, or add **labels** — `true` / `"majors"` labels every major tick, `"ends"` only the first and last, and an object sets the label domain (`min` / `max`, default 0 → 100), a `format` function and a `color`.

### Zones

`zones` marks coloured ranges on the 0–100 scale (`{ from, to, color }[]`, later zones win where they overlap). `zoneDisplay` chooses how they render: **`band`** (default) — a thin arc ringing the track; **`fill`** — the lit notches or solid fill take the zone colour where they overlap it; **`both`**.

### Sectors

`sector` fills the wedge from the start angle to the value. The default **`conic`** gradient brightens toward the leading edge (rendered as a CSS `conic-gradient` layer behind the SVG); **`radial`** brightens toward the rim; **`none`** paints a flat `color` — which can be any SVG paint, including `url(#pattern)` from a `PatternPreset` child. `opacity` is the peak opacity (default `0.85`) and `innerRadius` (fraction of the sector radius) hollows the middle. With `centerDisc` on, the sector starts at the disc's outer edge automatically.

`centerDisc` draws a ringed disc behind the center label — `radius` (fraction of size, default `0.19`), `fill` (default `var(--background)`), `stroke`, `strokeOpacity` and `strokeWidth` (px). It sits above sectors and needles, so a short needle disappears under it and a sector starts at its edge.

## Props

### Gauge

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `orientation` | `"arc"` \| `"linear"` | `"arc"` | Arc (default) or horizontal linear notch track |
| `value` | `number` | required | Fill level **0–100** |
| `centerValue` | `number` | — | Optional center statistic (NumberFlow); omit for no label |
| `labelPlacement` | `"top"` \| `"bottom"` \| `"left"` \| `"right"` | `"top"` | Label position for linear gauges (`top` / `bottom` recommended) |
| `labelAlign` | `"start"` \| `"center"` \| `"end"` | `"start"` | Horizontal alignment for linear label (left / center / right) |
| `totalNotches` | `number` | `40` | Notch count |
| `spacing` | `number` | `25` | **%** gap between notches |
| `notchLengthPercent` | `number` | `100` | Notch depth as **%** of default (5–100); lower = shorter notches |
| `notchWidthPercent` | `number` | `80` | Linear only — notch width as **%** of slot |

| `inactiveGradient` | `[string, string]` | same as active | Hex stops for inactive notches when `useGradient` |
| `activeFill` / `inactiveFill` | `string` | `chart-1` / `border` | Solid, CSS color, or `url(#patternId)` |

| `arcStyle` | `"notches"` \| `"solid"` \| `"none"` | `"notches"` | Arc only — notch track, one rounded stroke, or no track |

| `needle` | `boolean` \| `GaugeNeedleVariant` \| `GaugeNeedleOptions` | — | Arc only — pointer; `true` = `"gradient"` |

| `glow` | `boolean` \| `GaugeGlowOptions` | — | Arc only — soft glow on lit notches, solid arc and progress ring |
| `centerDisc` | `boolean` \| `GaugeCenterDiscOptions` | — | Arc only — ringed disc behind the center label |
| `enterTransition` | `Transition` | zero-bounce spring (`visualDuration: 0.9`) | Motion transition for the fill sweep (and needle, sector, ring, dots) |
| `enterStaggerScale` | `number` | `1` | Scales the delay before the sweep starts (0.25–2.5) |
| `defaultLabel` | `string` | `"Total"` | Center label |
| `formatOptions` | `ChartStatFlowFormat` | standard | NumberFlow format |
| `prefix` / `suffix` | `string` | - | Center prefix / suffix |
| `width` / `height` | `number` | - | Fixed size; omit for responsive |
| `minWidth` | `number` | `300` (arc) / `200` (linear) | Min width (px) when responsive |
| `className` | `string` | - | Root wrapper |
| `children` | `ReactNode` | - | Defs (`PatternPreset`, `*Gradient`, …) |

## Theming

Inactive (track) notches default to **`var(--border)`** — shared with ring tracks and radar grid lines. Active notches default to **`var(--chart-1)`**, as do sectors, progress rings and dots; rulers, needles and the center disc ring use **`var(--foreground)`** and the disc fill **`var(--background)`**, so dials follow light and dark mode. Override with `inactiveFill` / `activeFill`, or tune **`--border`** / **`--chart-1`** in your theme. See [Theming](/docs/theming).
