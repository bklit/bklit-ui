## Usage

`ComposedChart` is the time-series shell for **mixing marks** on one `data` array, one x-scale and as many y-axes as you need. Use **`SeriesBar`** for vertical columns aligned to dates (not the categorical `<Bar />` from `BarChart`, which uses a band scale).

Every time-series primitive composes. Each one registers with the shared y-domain and the tooltip automatically, including inside fragments:

| Child | Notes |
|-------|-------|
| `SeriesBar` | Grouped or stacked columns. `yAxisId` puts bars on their own scale. |
| `Line` / `Area` | Any curve, markers, dashed tails, edge fades. |
| `Scatter` | Points with hover dimming. `radius`, rings, `yAxisId`. |
| `Candlestick` | Reads `open` / `high` / `low` / `close` from each row. Its axis **floats** around the wicks instead of starting at zero. Size with `widthRatio` (default `0.6`). |
| `ProfitLossLine` | Recolours above and below zero. |
| `Band`, `ProjectionLine`, `TrendLine`, `ReferenceArea` | Extend the domain and draw in the same plot. |

The chart also takes the `LineChart` lifecycle props: `status` / `loadingLabel` for loading states, `xDomain` / `xDomainSlotCount` for brush zoom, and `yDomainTween`.

- **`aspectRatio`** — wide charts (e.g. `4 / 1`) work for full-width heroes; in **narrow cards** use **`3 / 2`** or **`2 / 1`** so the plot stays tall enough to read.
- **`barSize`**, **`maxBarSize`**, **`barGap`** — parent-level layout for `SeriesBar` groups (similar to Recharts `ComposedChart` props). Use **`barGap={0}`** and a higher **`maxBarSize`** for dense daily data so columns read like the [90 days of data](/docs/components/bar-chart#90-days-of-data) bar example.
- **`stacked`** / **`stackGap`** — stack `SeriesBar` segments in child order at each x (other series are not stacked). The bars' axis fits the stack totals, even with a second y-axis.
- **`yDomains`** — per-axis domain overrides keyed by `yAxisId`: a fixed `[min, max]` or a function of the auto domain. Hoist the object out of render.
- **`SeriesBar`** — default **`radius` is 0** (square tops). Pass **`radius={4}`** (or similar) for rounded corners.
- **`Line`** / **`Area`** — pass a **`curve`** from `d3-shape` (e.g. **`curveMonotoneX`**) to soften paths when you have many daily points.
- **Muted context bars** — bars read best as quiet context under a bold line: fill them with the series colour at low strength, e.g. `color-mix(in oklch, var(--chart-3) 32%, transparent)`, and set `stroke` to the full colour for the tooltip dot.
- **`Line`** / **`Area`** — use **`showMarkers`** for scatter-style ring markers at each point; pass **`markers={{ radius, ringGap, strokeWidth }}`** to tune styling.
- **`Line`** / **`Area`** — use **`dashFromIndex`** and **`dashArray`** for a dashed tail on incomplete periods (the dashed segment follows the same curve and edge fade).
- **`XAxis`** — default ticks snap to data rows so the crosshair aligns. Tune **`numTicks`** for dense series (e.g. daily). Use **`tickMode="domain"`** only when you want calendar-even spacing instead of data alignment.
- **`ChartTooltip`** — for bar-heavy layouts, **`showCrosshair={false}`** often looks cleaner because the hover band is already vertical columns.
- **`YAxis`** / **`yAxisId`** — every series takes a `yAxisId` (see [Y Axis](/docs/utility/axis/y-axis)). Ids are free-form: an axis without a `<YAxis>` is a hidden scale, handy for volume bars.
- **Hover dimming** — `SeriesBar` fades non-hovered columns using `tooltipData.index`, like grouped bars in `BarChart`. Tune with **`fadedOpacity`** on each `SeriesBar`.

### Basic example

The preview above: daily revenue as points, its smoothed 7-day trend inside an expected-range band, and orders as quiet bars on a hidden axis. Rows look like `{ date, revenue, trend, low, high, orders }`.

```tsx
import {
  Band,
  ChartTooltip,
  ComposedChart,
  Grid,
  Line,
  Scatter,
  SeriesBar,
  XAxis,
  type YDomainOverride,
} from "@bklitui/ui/charts";
import { curveCatmullRom } from "d3-shape";

const smooth = curveCatmullRom.alpha(0.42);
// Orders fill the bottom third on their own axis; the revenue axis floats
// (from the data's min / max) so the band and points use the top two-thirds.
const yDomains: Record<string, YDomainOverride> = {
  orders: ([, max]) => [0, max * 3],
  left: [minValue - range * 0.6, maxValue + range * 0.05],
};

export default function Example({ data }) {
  return (
    <ComposedChart aspectRatio="2 / 1" data={data} maxBarSize={14} yDomains={yDomains}>
      <Grid horizontal />
      <SeriesBar
        dataKey="orders"
        fill="color-mix(in oklch, var(--chart-3) 30%, transparent)"
        radius={3}
        stroke="var(--chart-3)"
        yAxisId="orders"
      />
      <Band
        curve={smooth}
        fill="var(--chart-1)"
        fillOpacity={0.22}
        fillType="gradient"
        label="Expected"
        lowerKey="low"
        strokeDasharray="3,4"
        strokeOpacity={0.5}
        upperKey="high"
      />
      <Scatter
        dataKey="revenue"
        fill="color-mix(in oklch, var(--chart-2) 75%, transparent)"
        radius={3.5}
      />
      <Line curve={smooth} dataKey="trend" stroke="var(--chart-1)" strokeWidth={2.5} />
      <ChartTooltip />
      <XAxis numTicks={6} />
    </ComposedChart>
  );
}
```

See the [charts gallery](/charts/composed-chart) for stacked bars, pattern fills, rounded bars, and more compositions.

### Price and volume

Candles on a floating right axis, volume on a hidden zero-based axis. `yDomains` keeps the two from overlapping: volume fills the bottom quarter and the price floor drops so the candles sit above it.

### Background

Use [`Background`](/docs/utility/background) instead of `Grid` for a pattern fill behind bars and lines. See **Pattern Background** examples on the [composed chart gallery](/charts/composed-chart).

### Trend line

Add a [`TrendLine`](/docs/utility/trend-line) per series you want to fit (bars or lines), after the series children so it draws on top. See the **Trend Line** examples on the [composed chart gallery](/charts/composed-chart).

```tsx
<SeriesBar dataKey="units" fill="var(--chart-3)" />
<Line dataKey="revenue" stroke="var(--chart-1)" />
<TrendLine dataKey="revenue" stroke="var(--chart-1)" />
```

### Weekends and deadlines

[`Weekends`](/docs/utility/weekends) shades the weekend columns and [`Deadline`](/docs/utility/deadline) marks a due date. With `SeriesBar` columns at midnight, `Weekends` centres each band on its column automatically; pass `utc` when your dates are UTC-anchored (like `composedDemoData`).
