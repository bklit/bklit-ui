## Usage

`Weekends` draws a band over every weekend span on a date x axis. Place it as a child of `LineChart`, `AreaChart`, `ComposedChart`, `CandlestickChart`, or `BarChart` (with date rows). It renders in the underlay layer — above grid and background, behind series.

```tsx
import { LineChart, Line, Grid, Weekends, ChartTooltip, XAxis } from "@bklitui/ui/charts";

<LineChart data={data}>
  <Grid horizontal />
  <Weekends />
  <Line dataKey="completed" />
  <XAxis />
  <ChartTooltip />
</LineChart>
```

- **Time scales** (line, area, composed, candlestick) — only spans inside the visible x-domain are drawn, so brush zoom and long ranges stay cheap. When one day is narrower than `minDayWidth` pixels (e.g. multi-year ranges), nothing renders.
- **Band scales** (`BarChart`) — consecutive weekend columns merge into one band that covers the full column slots. Dates are read from the first field holding a `Date` or a `"YYYY-MM-DD"` string; pass `dateKey` to pick one. Horizontal bar charts shade rows instead of columns.
- **Locales** — set `weekendDays` with `Date#getDay()` numbers (0 = Sunday … 6 = Saturday), e.g. `[5, 6]` for Friday–Saturday weekends.
- **Time zones** — day boundaries use local time. Pass `utc` when your dates are anchored to UTC (e.g. ISO strings ending in `Z`).
- **Alignment** — by default bands run midnight to midnight. On a `ComposedChart` with `SeriesBar` columns at midnight, `align="auto"` shifts bands half a day so each column sits inside its day.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `weekendDays` | `number[]` | `[6, 0]` | Days that count as weekend (`Date#getDay()` numbers) |
| `fillType` | `"pattern" \| "solid"` | `"pattern"` | Diagonal stripes or a solid fill |
| `fill` | `string` | `var(--chart-foreground-muted)` | Stripe / fill colour |
| `fillOpacity` | `number` | `0.45` (pattern), `0.08` (solid) | Fill opacity |
| `pattern` | Pattern preset id | `"diagonal"` | Pattern when `fillType` is `"pattern"` (see [Background](/docs/utility/background)) |
| `patternScale` | `number` | `1.5` | Pattern tile scale |
| `patternStrokeWidth` | `number` | `1` | Stripe width |
| `align` | `"auto" \| "calendar" \| "centered"` | `"auto"` | `calendar` = midnight to midnight; `centered` = shifted half a day so daily points sit mid-band |
| `utc` | `boolean` | `false` | Use UTC day boundaries |
| `minDayWidth` | `number` | `2` | Skip rendering when one day is narrower than this (px) |
| `dateKey` | `string` | auto | Band (bar) scales only — data key holding each row's date |
| `className` | `string` | — | Class on the root `<g>` |

The date math is exported as `computeWeekendRanges(start, end, options)` (time domains) and `computeWeekendIndexRuns(dates, options)` (row runs) if you need the spans elsewhere — for example to skip weekends in a tooltip.

## Examples

### Brush zoom

Bands are recomputed from the visible domain, so zooming in reveals weekends that were too narrow to draw at full range.

<ComponentShowcase code={`<ChartBrushLayout data={data} enabled height={72} brushStrip={...}>
  {(layout) => (
    <LineChart
      data={data}
      xDomain={layout.xDomain}
      xDomainSlotCount={layout.xDomainSlotCount}
      tweenYDomainOnXDomainChange
    >
      <Grid horizontal />
      <Weekends />
      <Deadline date={new Date(2026, 9, 1)} label="Launch" />
      <Line dataKey="value" />
      <XAxis />
      <ChartTooltip />
    </LineChart>
  )}
</ChartBrushLayout>`}
  liveChartPreview
  previewMinHeight={360}
>

</ComponentShowcase>
