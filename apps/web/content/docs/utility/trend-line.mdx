## Usage

`TrendLine` fits a straight line through one series (`dataKey`) using linear least squares and draws it across the full data range. Place it as a child of `LineChart`, `AreaChart`, `BarChart` (vertical or horizontal), or `ComposedChart` — **after** the series so it draws on top.

```tsx
import { LineChart, Line, Grid, TrendLine, ChartTooltip, XAxis } from "@bklitui/ui/charts";

<LineChart data={data}>
  <Grid horizontal />
  <Line dataKey="value" />
  <TrendLine dataKey="value" />
  <XAxis />
  <ChartTooltip />
</LineChart>
```

On time-series charts the fit uses the date as x. On `BarChart` it uses the category index, so the line runs through bar centers (and along the value axis when `orientation="horizontal"`). Non-numeric values are skipped. The line fades in with the chart reveal (after bars land) and tweens to the new fit when data changes.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `dataKey` | `string` | — | Series key to fit (required) |
| `stroke` | `string` | `var(--chart-line-primary)` | Stroke color |
| `strokeWidth` | `number` | `2` | Stroke width |
| `strokeStyle` | `"solid" \| "dashed" \| "gradient"` | `"dashed"` | Stroke style |
| `strokeDasharray` | `string` | `"6,4"` | Dash pattern when `strokeStyle` is `"dashed"` |
| `gradientStart` | `string` | `stroke` | Gradient start color when `strokeStyle` is `"gradient"` |
| `gradientEnd` | `string` | `var(--chart-5)` | Gradient end color when `strokeStyle` is `"gradient"` |
| `fadeEdges` | `boolean \| "left" \| "right"` | `false` | Fade the line ends to transparent |
| `fadeEdgesLength` | `number` | `15` | Fade zone as % of line length per faded end (0–50) |
| `opacity` | `number` | `1` | Line opacity |
| `yAxisId` | `string` | `"left"` | Y-scale group id (biaxial charts) |
| `animate` | `boolean` | `true` | Fade in on reveal and tween on data change |
| `className` | `string` | `"chart-trend-line"` | Class on the wrapping `<g>` |

## Studio

Open [Studio](/studio?chart=line-chart) and select **Trend line** in the layers panel to pick the series and tune the stroke, gradient, and edge fade. The same layer is available on area, bar, and composed charts.
