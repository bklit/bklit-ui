## Usage

`ProjectionLine` draws a segment from the last data row (the anchor) into the future. It renders outside the series reveal clip so the horizon stays visible while the main line animates in.

Build the path with `buildProjectionPath`, or pass manual `{ date, value }[]` points. Pair with [`LineSeriesTerminalMarker`](/docs/utility/projection-line#terminal-marker) at the anchor when you want a ring at the hand-off.

```tsx
import {
  buildProjectionPath,
  ChartTooltip,
  Grid,
  Line,
  LineChart,
  LineSeriesTerminalMarker,
  ProjectionLine,
  XAxis,
} from "@bklitui/ui/charts";

const projectionPath = buildProjectionPath({
  sourceData: chartData,
  seriesKey: "value",
  mode: "target",
  pathDensity: "endpoints",
  horizonPoints: 6,
  endValue: 301,
});

<LineChart data={chartData}>
  <Grid horizontal />
  <Line dataKey="value" strokeWidth={2} />
  <LineSeriesTerminalMarker dataKey="value" />
  <ProjectionLine
    data={projectionPath}
    strokeDasharray="1,4"
    curveKind="bezier"
    strokeStyle="gradient"
    gradientStart="oklch(0.979 0.037 110.273)"
    gradientEnd="oklch(0.59 0.17 166.38)"
    showEndMarker
  />
  <XAxis />
  <ChartTooltip />
</LineChart>
```

The chart extends its x-domain to fit the projection horizon. Projections are intended for line charts without [brush zoom](/docs/utility/brush) — the two features are not supported together.

## ProjectionLine props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `ProjectionPoint[]` | required | Anchor + horizon points (`{ date, value }`) |
| `yAxisId` | `string \| number` | `"left"` | Y-scale group id |
| `stroke` | `string` | `var(--chart-3)` | Solid stroke color |
| `strokeStyle` | `"solid" \| "gradient"` | `"solid"` | Solid or path-aligned gradient stroke |
| `gradientStart` | `string` | `stroke` | Gradient start when `strokeStyle` is `"gradient"` |
| `gradientEnd` | `string` | `var(--chart-5)` | Gradient end when `strokeStyle` is `"gradient"` |
| `strokeWidth` | `number` | `2` | Stroke width |
| `curveKind` | `"linear" \| "bezier"` | `"linear"` | Straight segment or horizontal-tangent S-curve |
| `strokeDasharray` | `string` | `"6,4"` | Dash pattern |
| `strokeOpacity` | `number` | `1` | Stroke opacity |
| `showEndMarker` | `boolean` | `true` | Horizon endpoint dot |
| `endpointRadius` | `number` | `5` | Horizon marker radius |
| `endMarkerFill` | `string` | end colour | Horizon marker fill — pass `var(--background)` for a hollow ring |
| `showEndLabel` | `boolean` | `false` | Print the projected value above the horizon marker |
| `formatEndLabel` | `(value: number) => string` | `toLocaleString()` | End label formatter |
| `endLabelColor` | `string` | end colour | End label colour |
| `areaFill` | `"none" \| "solid" \| "gradient" \| "pattern"` | `"none"` | Fill under the projection, down to the baseline |
| `areaColor` | `string` | end colour | Area colour (`gradientEnd` or `stroke`) |
| `areaOpacity` | `number` | `0.12` / `0.3` / `0.5` | Area opacity (solid / gradient / pattern) |
| `areaFadeBottom` | `number` | `100` gradient, else `0` | Fade the area out over the bottom N% (0–100) |
| `areaPattern` | `PatternPresetId` | `"diagonal-up"` | Pattern preset when `areaFill="pattern"` |
| `areaPatternScale` | `number` | `1.5` | Pattern scale |
| `areaPatternTint` | `number` | `0` | Pattern only — opacity of a gradient wash under the pattern |
| `target` | `number` | — | Goal value: dashed horizontal line + ring where the projection crosses it |
| `targetStroke` | `string` | `var(--muted-foreground)` | Goal line colour |
| `targetDasharray` | `string` | `"4,4"` | Goal line dash |
| `targetStrokeOpacity` | `number` | `0.6` | Goal line opacity |
| `showTargetMarker` | `boolean` | `true` | Ring (with glow) on the goal crossing |
| `showGuides` | `boolean` | `false` | Dashed verticals at the hand-off and the goal crossing |
| `guideStroke` | `string` | `var(--muted-foreground)` | Guide colour |
| `guideStrokeOpacity` | `number` | `0.35` | Guide opacity |

## buildProjectionPath

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `sourceData` | `Record<string, unknown>[]` | required | Chart rows |
| `seriesKey` | `string` | required | Y value key |
| `xDataKey` | `string` | `"date"` | X value key |
| `mode` | `"auto" \| "target" \| "manual"` | required | How future points are generated |
| `autoMethod` | `"linearRegression" \| "lastSegment"` | `"linearRegression"` | Slope for `mode="auto"` |
| `pathDensity` | `"stepped" \| "endpoints"` | `"endpoints"` | Stepped path vs anchor + end only |
| `horizonPoints` | `number` | `6` | Future intervals for auto/target modes |
| `endValue` | `number` | — | Target Y when `mode="target"` |
| `points` | `ProjectionPoint[]` | — | Manual path when `mode="manual"` |
| `startIndex` | `number` | last row | Anchor row index |

## Terminal marker

`LineSeriesTerminalMarker` renders a dot at the last data point for the given `dataKey`, with a ring around it when `ringGap` is set. It fades in after the clip reveal completes.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `dataKey` | `string` | required | Series to anchor |
| `yAxisId` | `string \| number` | `"left"` | Y-scale group id |
| `fill` | `string` | same as `stroke` | Dot fill. Pass `transparent` for a hollow marker |
| `stroke` | `string` | `var(--chart-1)` | Ring color |
| `radius` | `number` | `5` | Dot radius |
| `ringGap` | `number` | `0` | Gap between dot and ring |
| `strokeWidth` | `number` | `1.5` | Ring stroke width |

### Projection area and goal

Give the forecast its own fill with `areaFill` — `"solid"`, a fading `"gradient"`, or a `"pattern"` hatch (add `areaFadeBottom` and `areaPatternTint` for a hatch over a gradient). `target` draws a goal line and rings the point where the forecast crosses it; `showGuides` drops dashed verticals from the hand-off and the crossing.
