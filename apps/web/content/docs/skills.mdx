Skills give AI coding agents project-aware context about Bklit UI. Once installed, your agent knows how to install charts from the `@bklit` registry, import them from the files the CLI wrote, compose and theme them, style them with Bklit's design vocabulary, and migrate existing charts.

For example, you can ask your agent to:

- "Add an area chart with tooltips to my dashboard."
- "Build a KPI stat card with a revenue sparkline."
- "Give the bar chart rounded tops and a diagonal pattern that matches our theme."
- "Replace our Recharts line chart with the Bklit one."
- "Fix the crosshair color on my candlestick chart tooltip."

## Install

```bash
npx skills add bklit/bklit-ui
```

This installs all three public skills. To install just one, pass `--skill`:

```bash
npx skills add bklit/bklit-ui --skill bklit-ui
npx skills add bklit/bklit-ui --skill bklit-ui-design
npx skills add bklit/bklit-ui --skill bklit-ui-migrate
```

Your agent loads each skill automatically when a request matches it. Learn more about skills at [skills.sh](https://skills.sh/docs/).

## Public skills

| Skill | Use it for |
|-------|-----------|
| **bklit-ui** | Installing, importing, composing, theming, and animating charts — the core skill |
| **bklit-ui-design** | How charts look: patterns and textures, rounded / squircle / 3D bars, edge fades, gradients, loading looks, and matching your app's theme |
| **bklit-ui-migrate** | Moving from Recharts or shadcn `ChartContainer` charts to Bklit equivalents |

## What bklit-ui covers

### Project context

The skill runs `shadcn info --json` to read your project's framework, Tailwind version, aliases, and installed components (agents that don't run the injection are told to run it themselves). If the `@bklit` registry isn't configured, it falls back to adding the namespace or installing by URL.

### Installation and imports

Charts install as source with the shadcn CLI:

```bash
npx shadcn@latest add @bklit/line-chart
```

Files land in `components/charts/`, so imports use your project's alias — for example `@/components/charts/line-chart`, `@/components/charts/tooltip`, and `@/components/charts/chart-context` for `chartCssVars`. After installing, the agent reads the installed source to confirm props, since you own that code.

### Composition and theming

Root chart → `Grid` → series → axes → overlays → `ChartTooltip`; `chartCssVars` for typed tokens; series colors from `--chart-1` … `--chart-5`, which `shadcn add` leaves untouched if your theme already defines them; sequential `--chart-scale-01` … `--chart-scale-05` for heatmaps and choropleths.

### Tooltips, overlays, animation, and loading

`ChartTooltip` props (`content`, `rows`, `indicatorColor`, `dotVariant`, …), legends, markers, reference areas, projection lines, backgrounds, enter-animation defaults and replay, and the `status="loading"` hand-off.

### Catalog

17 chart items — area, bar, line, live line, composed, scatter, candlestick, profit/loss line, pie, ring, radar, gauge, heatmap, funnel, sankey, sunburst, and choropleth — plus add-ons (axes, grid, tooltip, legend, markers, background, patterns, reference area, projection line, bar depth, stat flow) and stat-card blocks, each with install commands and links to [docs](/docs/components), the [charts gallery](/charts/area-chart), and [Studio](/studio).

## Contributing to bklit-ui

If you cloned the [bklit-ui repository](https://github.com/bklit/bklit-ui) to contribute, contributor-only skills live in `.agents/skills/` (see `AGENTS.md`):

| Skill | Purpose |
|-------|---------|
| **bklit-studio** | Build or edit charts: prototype in `/studio`, edit `packages/studio` and `packages/ui` |
| **bklit-ship** | Ship a chart from Studio to docs, gallery, and the shadcn registry |
| **bklit-studio-chart-performance** | Audit and fix Studio chart FPS, pan/zoom jank, and Motion subscriptions |
| **pr-open** | Commit, push, and open a PR with the bklit-ui checklist |
| **unit-tests** | Add tests without over-testing |

These skills are marked `internal` in their frontmatter, so `npx skills add bklit/bklit-ui` does not install them — they are for monorepo development only.
