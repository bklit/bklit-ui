`Gauge` has a new `orientation="linear"` mode that lays its notches along a horizontal bar — the same geometry, fills, gradients and enter animations as the arc, in a shape that fits table rows and cards.

The center label is optional. In linear mode, place it above or below the track with `labelPlacement` and align it with `labelAlign` — the same six positions as a chart legend.

See the [Gauge docs](/docs/components/gauge-chart).
