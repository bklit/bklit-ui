The hardest part of a good chart is rarely the data — it's the look. [Recipes](/recipes) is a gallery of finished treatments you can lift straight into your app: faded pattern backgrounds, squircle bars, custom hover indicators, event markers, forecasts, range bands, heatmap and donut styles.

## One look, every chart

Pick a recipe, then switch between the charts it applies to. Each one shows the exact code for that chart, so you are never translating a bar-chart example into an area chart by hand.

## Prompts for your agent

Every recipe ships with a prompt written for the [Bklit UI agent skills](/docs/skills) — per chart, or for all charts at once. Paste it into your coding agent and it applies the treatment to the charts already in your codebase, using the right components and props.

## Studio, tidied up

Layer visibility now works across every chart in [Studio](/studio): toggling a layer's eye hides it in the preview, whichever chart you're editing. Settings that silently did nothing are either wired up or gone, and the palette switcher animates between its list and customise views.

Recipes replaces Blocks in the site navigation. The [Blocks](/blocks) page is still there.
