title: Patterns

---

`PatternPicker` renders a row of pattern swatches used inside `FillPicker` when fill mode is **Pattern**.

**Source:** `packages/studio/src/components/controls/pattern-picker.tsx`

<ComponentShowcase>
  <StudioUiPreview>
    <PatternsDemo />
  </StudioUiPreview>
</ComponentShowcase>

Swatches are rendered with `renderPatternPreset` from `@bklitui/ui/charts` (Nucleo-based presets, see `packages/ui/src/charts/pattern-preset.tsx`). IDs match `PatternPresetId`; the full list is `PATTERN_PRESET_IDS` / `PATTERN_PRESETS`, documented on the [Patterns docs page](https://bklit.com/docs/utility/patterns).
